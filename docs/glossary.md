# BJCP 术语表与翻译规范（中译英 反查原文用，英→中翻译用）

## 硬性规则
1. 所有数字、数值区间、单位、缩写一律保留原文不译：OG、FG、IBU、SRM、ABV、%vol、°P、°L、EBC、plato、psi、ppm 等。
2. 商业品牌与产品名不译（Bud Light、Pilsner Urquell、Guinness 等），保留原文。
3. 结构必须与原文一致：段落数一致、换行一致；以 "- " 开头的列表行保留为 "- " 列表；原文中的 **加粗** 与 _斜体_ 标记要原样保留位置，只译其中的文字。
4. 逐句完整翻译，不得省略、概括、合并段落；不得自创内容。
5. 技术词一致性优先，见下表；拿不准的保留英文并在其后用括号给出中文（仅第一次出现可省略）。
6. 译文使用简体中文，术语选择国内精酿常用译名。

## 风格家族词（统一译法）
- lager 拉格；ale 艾尔；pilsner/pils 皮尔森；porter 波特；stout 世涛；bock 博克；doppelbock 双料博克；weizen/wheat beer 小麦啤酒；weissbier 小麦白啤；hefeweizen 酵母小麦啤；witbier 白啤；saison 赛松；biere de garde 法国窖藏啤酒；lambic 兰比克；gueuze 贵兹；kriek 樱桃兰比克；faro 法柔；gose 戈斯；berliner weisse 柏林白啤；altbier 老式啤酒（Alt）；kölsch 科隆啤酒；bitter 苦啤（英式）；mild 淡味艾尔；scotch ale 苏格兰艾尔；old ale 老艾尔；barleywine 大麦酒；brown ale 棕色艾尔；cream ale 奶油艾尔；steam beer 蒸汽啤酒（加州蒸汽）；IPA：保留 "IPA"，正文可用“IPA（印度淡色艾尔）”仅首次出现处；double/triple IPA 双料/三料 IPA；imperial 帝国（用于 Imperial Stout=帝国世涛 等）；session 佐餐/畅饮型；malt liquor 麦芽烈酒；ice beer 冰馏啤酒；rye beer 黑麦啤酒；fruit beer 水果啤酒；spiced/herb/vegetable beer 香料/药草/蔬菜啤酒；smoked beer 烟熏啤酒；wood-aged 木桶陈酿；sour 酸；wild ale 野菌艾尔；mixed-fermentation 混合发酵；cider 苹果酒/西打；perry 梨酒；mead 蜂蜜酒；braggot 博拉格特（蜂蜜大麦酒）；melomel 水果蜂蜜酒；cyser 苹果蜂蜜酒；pyment 葡萄蜂蜜酒；hydromel 低度蜂蜜酒；sack mead 高度蜂蜜酒；acerglyn 枫糖蜂蜜酒。

## 常用感官与工艺词
- body 酒体；mouthfeel 口感；carbonation 二氧化碳含量/杀口感（可用“碳化”）；finish 收口（也可“回味”）；
- bitterness 苦味/苦度；balance 平衡；attenuation 发酵度（attenuated=发酵彻底的/干爽）；
- aroma 香气；flavor 风味；appearance 外观；head 泡沫；retention 泡沫持久度；lacing 挂杯；clarity 澄清度；haze 浑浊（chill haze 冷雾浑浊）；brilliant 通透/晶亮；
- malt 麦芽（maltiness 麦芽感；grainy 谷物感；bready 面包感；toasty 烤面包感；biscuity 饼干感；toffee/caramel 太妃糖/焦糖；honey 蜂蜜）；hoppy 酒花感强的；hop aroma/flavor 酒花香气/风味；dry-hop 干投酒花；noble hops 贵族酒花；spicy/floral/herbal/citrus/pine/resin/dank 辛香/花香/草本/柑橘/松木/树脂/阴湿（dank 可“大麻阴湿感”）；esters 酯香（果香酯）；phenols 酚类；banana 香蕉；clove 丁香；bubblegum 泡泡糖；diacetyl 双乙酰（奶油/黄油味）；DMS 二甲基硫（玉米味）；sulfur 硫味；yeasty 酵母味；clean 纯净/干净的；crisp 清爽干脆；dry 干爽；sweet 甜；smooth 顺滑；creamy 奶油般；velvety 丝绒般；astringent 收敛/涩；tannin 单宁；acidity 酸度；acetic 醋酸；lactic 乳酸；funky 野菌/臭香（funky=“野性”）；brett 布雷特酵母；
- lagering 低温熟成/拉格熟成；fermentation 发酵；cold conditioning 冷贮；warm fermentation 高温发酵；attenuate 发酵彻底；esters 醇香；grainy 谷香；
- adjunct 辅料（rice 大米、corn 玉米、sugar 糖）；n/a。

## 常见固定句（遇到直接套用，保持一致）
- "Standard description applies." -> "适用标准描述。"
- "Standard description applies for remainder of characteristics." -> "其余特征适用标准描述。"
- "Varies by base style." -> "随基酒风格而定。"
- "Varies by base style and special ingredients." -> "随基酒风格与特殊原料而定。"
- "See preamble for intent." -> "意图见本类总述。"
- "No set ranges." -> "无固定范围。"
- "None." -> "无。"
